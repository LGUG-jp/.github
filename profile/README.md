# LGUG — Local Government Underground

LGUGは、自治体職員等の有志が、AI活用やソフトウェア開発、GitHubによる共同開発を実践する非公式の技術コミュニティです。

個人の自主的な学習・試作・検証を大切にしながら、自治体の枠を超えて知識や成果物を共有し、誰もが利用・改善できる便利なツールを育てています。

特定の自治体の公式事業ではなく、参加者がそれぞれの立場で活動しています。

## 主なプロジェクト

- [AppBox](https://github.com/LGUG-jp/appbox-web) — 日常のちょっとした作業を便利にするWebアプリ集
- [Netarium](https://github.com/LGUG-jp/netarium) — ネットワーク構成図と機器情報の管理ツール

## 共同開発について

アイデアの提案、Issueでの意見交換、ソースコードの改善など、できる範囲での参加を歓迎します。

各プロジェクトのライセンスと開発ルールを尊重し、所属組織や第三者の権利を侵害しない範囲で活動します。

目指すのは、誰かが一人で作り続けるのではなく、みんなで便利なものを少しずつ育てていくことです。
